# Solaria service artwork proposals

Three independent service scenes derived from the six reviewed hub mission illustrations and the shared neutral backdrop. All final PNG files are exactly 1881 x 836 pixels (9:4), confirmed from their PNG headers. Generated with the built-in image_gen tool.

- Refuel: young male attendant in teal/orange overalls, tanks, pump and connected spacecraft fuel hose.
- Repair: auburn-haired female mechanic with tools, damaged hull plate and spacecraft maintenance bay.
- Market: older bald bearded merchant with goods, display shelving and trade terminal.

The three characters differ from each other and from the original mission official. No screen bindings have been changed. These are proposals for visual review.

Exact prompts: [prompts-v1.json](prompts-v1.json). Source references and output sizes: [manifest-v1.json](manifest-v1.json).
